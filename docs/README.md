# Project documentation

Human-readable specs for the behavioral chronic-pain primary-outcome cohort.

| Document | Purpose |
|---|---|
| [COHORT_FILTERING_RULES.md](COHORT_FILTERING_RULES.md) | **Inclusion / exclusion** at the condition stage (including acute population rules) |
| [DATA_COLUMNS.md](DATA_COLUMNS.md) | **Column dictionary** for `data/processed/studies.csv` and `primary_outcomes.csv` |
| [category_mapping.md](category_mapping.md) | **Outcome and intervention category tables** (patterns, instruments, distributions); auto-generated by `finalize_cohort`, never hand-edited |
| [../analysis/outcome_analysis.ipynb](../analysis/outcome_analysis.ipynb) | **Analysis notebook**: trials over time, cohort summary, exclusions, conditions, interventions, intervention x outcome cross-tab (filterable). Re-executed by `finalize_cohort`; figures (PNG/PDF) and tables (CSV) saved next to it |
| [../analysis/results_summary.md](../analysis/results_summary.md) | **Results summary** (auto-generated after every notebook run, numbers recomputed from the data): the Psychological & cognitive finding (alone vs combined) with its figures, then an overview of all other results |
| [COHORT_REPRODUCTION_GUIDE.md](COHORT_REPRODUCTION_GUIDE.md) | Commands to rebuild the cohort from raw JSON |

Statistics only: [`../data/processed/cohort_report.md`](../data/processed/cohort_report.md) (regenerated by `finalize_cohort`).
