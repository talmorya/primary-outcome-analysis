# Cohort reproduction guide

How to rebuild or refresh the **analytic cohort** frozen under `data/processed/final_cohort/` (run ID `final_cohort_20260922`, **666** eligible studies).

**Inclusion rules, pattern tables, and column semantics:** [`FINAL_INCLUSION_RULES.md`](FINAL_INCLUSION_RULES.md) (do not duplicate here).

**CT.gov extraction** (674 studies, separate layer): [`README.md`](README.md).

---

## Data dependencies

| Asset | Location | In git? |
|---|---|---|
| Raw CT.gov JSON | `data/raw/full/full_20260823_201251/studies/` | No (required for full rebuild from JSON) |
| Production extraction | `data/processed/full/full_20260823_201251/` | No (not modified by cohort scripts) |
| Headache expansion | `reports/exploration/headache_candidates_raw.json` | Yes |
| **Final cohort** | `data/processed/final_cohort/` | Yes |
| Review layer (intermediate) | `reports/exploration/revised_cohort/` | Yes (regenerated by build) |

Master pool = 674 extraction studies + 22 curated headache studies = **696** rows in `exclusion_audit.csv`.

## Commands

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

### Full rebuild (needs raw JSON)

```bash
PYTHONPATH=src python -m ctgov_pipeline.build_revised_cohort
PYTHONPATH=src python -m ctgov_pipeline.finalize_cohort
```

`finalize_cohort` expects **666** eligible studies (`EXPECTED_ELIGIBLE_STUDIES` in `finalize_cohort.py`), copies outputs to `data/processed/final_cohort/`, and writes `cohort_report.md` + `cohort_manifest.json`.

### Label refresh only (no raw JSON)

Re-applies classifiers from frozen `studies.csv` / `primary_outcomes.csv` intervention JSON and outcome text:

```bash
PYTHONPATH=src python scripts/refresh_revised_cohort_from_tables.py
PYTHONPATH=src python -m ctgov_pipeline.finalize_cohort
```

### Verify

```bash
PYTHONPATH=src python -m unittest \
  tests.test_finalize_cohort \
  tests.test_revised_cohort \
  tests.test_intervention_category_validation \
  tests.test_outcome_category_validation \
  tests.test_condition_eligibility -v
```

## Pipeline map (code entry points)

| Step | Module | Config |
|---|---|---|
| Condition eligibility | `condition_eligibility.py` | `condition_patterns_proposed.yaml` |
| Intervention categories | `classify_intervention_categories.py` | `intervention_categories.yaml` (v2.0.0) |
| Intervention inclusion | `intervention_eligibility.py` | (logic only) |
| Outcome categories | `outcome_category.py` | patterns in code + mechanistic lexicon |
| Outcome mechanism flags | `outcome_mechanism.py` | patterns in code (descriptive; **not** exclusion) |
| Build review layer | `build_revised_cohort.py` | all of the above |
| Freeze | `finalize_cohort.py` | — |

**Inclusion:** condition pass **and** intervention pass. Outcomes do not exclude studies.

## Limitations (cohort layer)

1. CT.gov `BEHAVIORAL` retrieval is broad; intervention categories describe treatment content on **active** arms.
2. Condition matching is text-based on registry fields.
3. Outcome and mechanism lexicons are heuristic; `outcome_category_review_flag` marks uncertain rows.
4. Headache expansion is a fixed NCT list in `build_revised_cohort.py`.
5. Full rebuild requires local raw JSON; refresh script works from frozen tables only.
